# pg_quiz 🐘

PostgreSQL 14 の日本語文書をもとにした、**PostgreSQL の理解および、OSS-DB 技術者認定試験（Silver / Gold）対策の五者択一/択複クイズアプリ**です。

ブラウザだけで動きます。インストールもアカウント登録も不要で、スマートフォンでも 1 問ずつ見やすく進められます。

## DEMO

https://kubo-4ka.github.io/pg_quiz/

> **⚠️ ご利用にあたって**
> 本アプリは個人が開発・公開している**非公式**の学習用アプリです。LPI-Japan（OSS-DB 技術者認定試験の運営団体）や PostgreSQL Global Development Group などの公式なものではなく、それらの団体とは関係ありません。
> 問題と解説は PostgreSQL 14 文書を参照し、正確さに注意して作成していますが、誤りや古い情報が含まれている可能性があります。お気づきの点がありましたら **Issues** でお知らせください。
> 試験の最新情報は必ず公式サイトでご確認ください。

## できること

|                            |                                                                                                                                                   |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| **通常モード**             | 選択肢を選ぶとその場で正誤・解説・参照ドキュメントを表示                                                                                          |
| **未出題モード**           | 一度も解いていない問題を優先して出題                                                                                                              |
| **復習モード**             | 間違えた問題を、連続 2 回正解するまで復習対象として管理                                                                                           |
| **模試モード**             | 出題範囲の重要度どおりに各カテゴリから出題（Silver 50 問 / Gold 30 問）、制限時間 80 分（本試験はアンケートを含めて 90 分）、採点後にまとめて解説 |
| **Ver 差分（試験範囲外）** | `pg_xlog` → `pg_wal`、`recovery.conf` の廃止など、バージョン間の主な変更点・非互換                                                                |
| **状況分析**               | 未出題・復習対象の割合、カテゴリ別の正答率、目標日と学習できる曜日から「学習日 1 日あたり何問」の目安を算出                                       |
| **挑戦履歴**               | 過去の結果と解説を再表示、間違えた問題だけに再挑戦                                                                                                |
| **出題タイプ**             | 「知識確認」と「状況判断」で絞り込んで挑戦                                                                                                        |
| **問題一覧**               | レベル・カテゴリ・出題タイプ・状態・キーワードで検索                                                                                              |
| **複数端末の統合**         | PC とスマートフォンなどの学習記録を、エクスポートしたファイルで 1 つにまとめる                                                                    |
| **オフライン**             | ホーム画面に追加すると、通信できない場所でも出題と解説を表示                                                                                      |
| **テーマ**                 | ライト / ミドル / ダーク                                                                                                                          |

解説にはすべて、根拠となる **PostgreSQL 文書へのリンク**が付いています（試験範囲の問題は PostgreSQL 14 日本語文書、Ver 差分の問題は各バージョンのリリースノートなど）。迷った箇所からそのまま原典を読めます。

## 出題タイプ

問題は次の 2 つのタイプに分かれていて、ホーム画面で絞り込んで挑戦できます。

- **知識確認** … 機能・仕様・既定値・構文などを問う問題
- **状況判断** … 設定ファイル、コマンドやビューの出力、サーバログ、発生している症状などを示し、「何が起きるか」「原因は何か」「どう対処するか」を判断させる問題

状況判断の問題に載せている PostgreSQL の出力やログは、実際に PostgreSQL 14 を動かして採取したものです。

解説には、その状況を再現したときの**実際の出力**（前後のサーバの状態、テーブルの中身、権限、サーバログ、実行計画など）を折り畳みで添えています。「そのとき何が見えるのか」を、解説と合わせて確認できます。

## 出題形式

試験サンプル問題にならい、次の形式を混ぜています。

- **単一選択**（「1 つ選びなさい」）… 選ぶと即座に正誤と解説が出ます
- **複数選択**（「2 つ選びなさい」「3 つ選びなさい」）… 指定数まで選んで「回答する」で確定。全部合っていた場合のみ正解です
- **否定形**（「**適切でないもの**を選びなさい」）… 読み違えを防ぐため、問題文中で赤く強調されます

## 収録数

**全 640 問**（うち状況判断 128 問）

| 区分                       |     問題数 | 内訳                                                    |
| -------------------------- | ---------: | ------------------------------------------------------- |
| **Silver**                 | **269 問** | 一般知識 32／運用管理 124／開発・SQL 113                |
| **Gold**                   | **313 問** | 運用管理 113／性能監視 87／チューニング 53／障害対応 60 |
| **Ver 差分**（試験範囲外） |  **58 問** | バージョン間の主な変更点・非互換                        |

公式の出題範囲に「重要な用語、コマンド、パラメータなど」として挙がっている用語は、すべてそのレベルの問題に登場します。

問題はすべて PostgreSQL 文書に基づくオリジナルで、OSS-DB 公式のサンプル問題や市販教材を転載したものではありません。

## PostgreSQL 文書のカバー状況

解説の参照先をもとに、PostgreSQL 14 日本語文書のどこまでを扱えているかを集計したものです。

|                                  | ページ数 |
| -------------------------------- | -------: |
| PG14 文書 全体                   |   約 840 |
| うち試験範囲に関係しうる章       |   約 650 |
| **本アプリが参照しているページ** |  **296** |

文書全体に対して **約 35%**、試験範囲に関係しうる章に対して **約 42%** です。

ただしこの比率は実態より低めに出ます。参照していない約 400 ページの内訳は次のとおりで、大半が「1 ページ＝ 1 項目」の辞書的なページだからです。

| 参照していないページの内訳                                           | ページ数 |
| -------------------------------------------------------------------- | -------: |
| SQL コマンドリファレンスの個別ページ（`CREATE OPERATOR CLASS` など） |      123 |
| システムカタログの個別ページ（`pg_attribute` など）                  |       56 |
| システムビューの個別ページ                                           |       25 |
| 関数リファレンスの細目                                               |       10 |
| 認証方式の細目（LDAP / PAM / RADIUS など）                           |        6 |
| contrib モジュール、その他                                           |   約 180 |

一方、**出題範囲の中心となる章はほぼ押さえています**。設定パラメータ（`runtime-config-*`）は 16 ページ中 14 ページ、バックアップ、継続的アーカイブ、定常的なバキューム作業、EXPLAIN の使用、統計情報の閲覧、ウォームスタンバイ、ホットスタンバイ、論理レプリケーション、データベースの物理的な格納といった章は参照済みです。

まとめると、**「試験に出る領域」に限ればおおむね網羅、文書全体で見ると 3 分の 1 強**、という状態です。残りは `CREATE OPERATOR` のような実務でも稀な構文や、拡張の開発者向け（SPI、PL/Perl、libpq の関数一覧など）で、試験にも実務にもほとんど出てこないと思われる領域です。

## 学習データについて

- 成績・履歴・目標はすべて**お使いのブラウザ内（localStorage）** に保存されます。サーバには一切送信されません。
- 端末やブラウザを変える場合は、「設定・データ管理」から **JSON でエクスポート／インポート**してください。
- インポートでは「**統合する**」と「**置き換える**」を選べます。統合すると、両方の端末の解答記録と履歴が重複なく 1 つにまとまり、成績や復習対象は解答した順に集計し直されます（設定と目標はインポート先の端末のものを使います）。
- インポートやリセットの直前の状態は 1 回分だけ保存され、「直前の状態に戻す」で元に戻せます。
- ブラウザのデータを消去すると、学習データも失われます。

## オフラインで使う

スマートフォンのブラウザで「ホーム画面に追加」（Android の Chrome では「アプリをインストール」）すると、アプリのように起動できます。一度開いた後は、通信できない場所でも出題と解説を表示できます（解説のリンク先の文書は通信が必要です）。
通信できるときは常に最新の問題データを読み込みます。
